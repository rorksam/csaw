## Fine-grained token (recommended — scoped to just this repo)
1. GitHub → your avatar (top-right) → **Settings**
2. Left sidebar, bottom → **Developer settings**
3. **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
4. Set:
   - **Name**: e.g. `colab-csaw`
   - **Expiration**: pick a short one (e.g. 30 days) — you can always regenerate
   - **Repository access** → *Only select repositories* → pick your `csaw` repo
   - **Permissions** → *Repository permissions* → **Contents: Read-only** (that's all a clone needs)
5. **Generate token**, then **copy it immediately** (starts with `github_pat_...` — it's shown only once)

Paste that string into `GIT_TOKEN = "..."` in the setup cell.

## Important security notes
- **Treat the token like a password.** Anyone with it can read your repo.
- **Don't commit the notebook with the token pasted in**, and don't share the Colab notebook with it filled — the cell source would leak it. The token is only meant to live in the running Colab runtime.
- If it ever leaks, go back to the same settings page and **revoke** it.

## My recommendation
For a CSAW CTF submission, **just make the repo public** and leave `GIT_TOKEN` empty — no token to manage or leak, and the notebook "just works" for anyone who opens it. Use the private + token route only if you need to keep the Trojan work non-public until after the competition.
